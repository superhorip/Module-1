1. SavingsAccount — накопительный счёт
Атрибуты:
- [ ] min_balance — минимальный неснижаемый остаток.
- [ ] monthly_interest_rate — месячная процентная ставка.
Методы:
- [ ] __init__() — вызвать конструктор родителя через super(), добавить новые атрибуты.
- [ ] withdraw() — запретить снятие, если после операции баланс станет меньше min_balance.
- [ ] apply_monthly_interest() — рассчитать проценты за месяц и начислить их на баланс.
- [ ] get_account_info() — добавить минимальный остаток и процентную ставку к информации родителя.
- [ ] __str__() — расширить строковое представление родителя.
Проверки:
- [ ] Минимальный остаток не может быть отрицательным.
- [ ] Процентная ставка должна быть корректной.
- [ ] При снятии учитывать ограничения родительского класса.


2. PremiumAccount — премиальный счёт
Атрибуты:
- [ ] withdrawal_limit — увеличенный лимит снятия.
- [ ] overdraft_limit — допустимая сумма ухода в минус.
- [ ] fixed_fee — фиксированная комиссия за операцию.
Методы:
- [ ] __init__() — инициализировать родителя и новые атрибуты.
- [ ] withdraw() — реализовать снятие с учётом лимита, овердрафта и комиссии.
- [ ] get_account_info() — добавить лимиты, овердрафт и комиссию.
- [ ] __str__() — расширить строковое представление.
Проверки:
- [ ] Сумма снятия не превышает лимит операции.
- [ ] Баланс после списания и комиссии не выходит за пределы овердрафта.
- [ ] Комиссия неотрицательная.
- [ ] Статус счёта разрешает операцию.
В ТЗ не указаны размеры лимитов и момент списания комиссии. Для учебной реализации можно самостоятельно задать эти правила.


3. InvestmentAccount — инвестиционный счёт
Атрибуты:
- [ ] portfolio — словарь с распределением вложенных сумм между типами активов.
- [ ] ALLOWED_ASSETS — допустимые типы: stocks, bonds, etf.
Методы:
- [ ] __init__() — вызвать конструктор родителя, создать портфель.
- [ ] Добавить метод покупки/вложения — перемещать деньги с доступного баланса в выбранный актив.
- [ ] withdraw() — переопределить снятие с учётом доступных средств.
- [ ] project_yearly_growth(growth_rates) — рассчитать ожидаемый годовой прирост портфеля.
- [ ] get_account_info() — добавить состав портфеля.
- [ ] __str__() — расширить строковое представление родителя.
Проверки:
- [ ] Тип актива входит в stocks, bonds, etf.
- [ ] Сумма вложения положительная.
- [ ] Для вложения достаточно доступных средств.
- [ ] Ставки доходности переданы корректно.
Демонстрационные ставки:
- stocks — 10% годовых.
- bonds — 4% годовых.
- etf — 7% годовых.
Метод вложения и разграничение свободного баланса и портфеля — моя рекомендация по реализации: ТЗ требует такие операции, но не задаёт их точный интерфейс.

Важный момент для PremiumAccount: твой текущий BankAccount.withdraw() запрещает отрицательный баланс. Поэтому для овердрафта недостаточно просто вызвать super().withdraw(). Потребуется изменить логику снятия в наследнике, сохранив необходимые проверки статуса и суммы.
